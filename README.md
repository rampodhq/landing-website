# Rampod Resolve Website

The launch site for Rampod Resolve, a founder-led service for turning contained engineering backlog issues into scoped, tested, and reviewed pull requests.

## Local Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Validation

```bash
npm run lint
npm test
```

The site is built with vinext and configured for OpenAI Sites hosting.
